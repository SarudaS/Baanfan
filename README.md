# 🥐 Baanfan Bakery Website

Welcome to the **Baanfan Bakery** website project! This is a responsive website designed to showcase delicious handmade pastries, cakes, and monthly baking promotions.

## ✨ Features
- **Home Page**: Features top-selling bakery items and current promotions.
- **Menu Directory**: Displays all available pastries, ingredients, and prices.
- **Contact Us**: Includes an interactive store map, opening hours, and a contact form.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Custom Styling)
- JavaScript (Interactivity)
